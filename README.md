# College Canteen Order Management System

## About the Project

The College Canteen Order Management System is a menu-driven
console-based application developed in C programming language.

This project is developed as a Data Structures and Algorithms
(DSA) project for managing food items and student orders in a
college canteen.

## Features

- Add new food items
- Display the canteen food menu
- Search food items by Food ID
- Sort food items by price
- Place a new food order
- Display all pending orders
- Process the next order
- Cancel an order
- Calculate total order amount

## Data Structures Used

### 1. Array
An array is used to store and manage food items in the canteen menu.

### 2. Structure
Structures are used to store information about food items and orders.

### 3. Linked List
A linked list is used to dynamically store and manage orders.

### 4. Queue
A queue is used to process orders according to FIFO
(First In, First Out).

## Algorithms Used

### Linear Search
Linear search is used to find a food item using its Food ID.

### Bubble Sort
Bubble sort is used to sort food items according to their prices.

## Technologies Used

- Programming Language: C
- Concepts: Data Structures and Algorithms
- Platform: Console / Terminal
